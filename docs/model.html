Two sides, and what each actor can reach

The system side builds the design system. The product side consumes it and never builds it. Only two things cross between them. Select anyone to see what they actually have – and watch the other side go dark.

The boundary is authorship, not visibility. Look, don’t edit. In Figma that already works – a product designer can read every component’s guidelines and every foundation, and change none of them. In code the same rule should hold and currently doesn’t, because the repository is private. That is a choice about the repo, not a property of the system.
